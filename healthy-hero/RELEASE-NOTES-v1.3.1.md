# Healthy Hero v1.3.1 — Kid Timing Update

- The obstacle timer no longer runs while narration is reading the question and answer choices.
- Narration now automatically reads all three answer choices.
- After narration finishes, children receive a 7-second reading/thinking grace period before the obstacle starts moving.
- Answer windows are now 30, 28, 26, 24, and 22 seconds across the five mission tiers.
- If narration is off, the same 7-second grace period is provided before the answer timer begins.
- Pressing READ restarts the full read/grace/answer cycle so a child can hear the prompt again without losing time.
- Cache version bumped to 1.3.1.
